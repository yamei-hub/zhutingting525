同一句需求，两种翻译

老师要的配置四条：① 无缝循环 ② 3.2 秒自动翻页、手动操作后不停止 ③ 圆点分页器可点击 ④ 初始效果 cube。 下面左右两个轮播都在真实运行——左边是第一轮提示词喂出来的，右边是第二轮补齐后的。别听我说，点一下两边的圆点，看那行读数发生了什么。

★1

两轮对照：只差一个 clickable两个轮播 HTML 完全一样，只有 JS 配置差一个 clickable，点圆点看读数

第 1 轮 · 漏了需求 圆点只能看，不能点

提示词里只写了"圆点分页器"，AI 理解成"把圆点画出来"，于是只给了 el，没给 clickable。圆点在，但点不动。

📋 需求 → 参数 对照（两条轮播其余配置完全相同）

老师提的需求对应参数第 1 轮 AI 给了吗第 2 轮补齐后
① 无缝循环loop: true❌ 漏了，拖到最后一张顶死✅ 首尾无缝衔接
② 3.2 秒自动翻页，手动后不停autoplay: { delay: 3200, disableOnInteraction: false }❌ 只给 delay，交互后自动停止✅ 拖动松手后继续自动翻
③ 圆点分页器可点击pagination: { el, clickable: true }❌ 只给 el，圆点不可点✅ 点圆点直接跳转
④ 初始效果 cubeeffect: 'cube'✅ 给了✅ 保留

🔁 第 1 轮提示词原文（漏项）

"帮我用 Swiper 写一个轮播初始化配置：new Swiper('#wySw4', {...})，要求能自动播放，每 3.2 秒翻一页，带圆点分页器，初始切换效果是 cube。"

  • 只写了名词（圆点、自动播放），没写行为（可点击、手动后不停、循环）
  • AI 按字面给了 3 条，漏 3 条体验类需求，控制台不报错

🔁 第 2 轮提示词原文（逐条说清）

"实测有 3 个问题，请补全：① 要无缝循环，加 loop: true；② 手动拖动、点圆点后自动播放不能停止，autoplay 加 disableOnInteraction: false；③ 圆点要能点击直接跳转，pagination 加 clickable: true。其它保持不变。"

  • 每条写成"参数名 + 取值 + 触发条件"，编号列出
  • AI 一次补齐 4 条，逐条实测通过
