任务一 · 提示词工程师不写代码写提示词：让 AI 生成 #wySw4 的配置（2 轮迭代）

目标需求：① 无缝循环 ② 3.2 秒自动翻页、手动操作后不停止 ③ 圆点分页器可点击 ④ 初始效果为 cube。

🔁 第 1 轮提示词（初版）

我（提示词 1）
帮我用 Swiper 写一个轮播初始化配置：new Swiper('#wySw4', {...})，要求能自动播放，每 3.2 秒翻一页，带圆点分页器，初始切换效果是 cube。
AI（回答 1）
好的，配置如下： 
new Swiper('#wySw4', {
  autoplay: { delay: 3200 },
  pagination: { el: '#wyPag4' },
  effect: 'cube',
  cubeEffect: { shadow: true, slideShadows: true }
});
每 3200 毫秒自动切换一张，圆点分页器挂在 #wyPag4 容器上，效果为 3D 立方体。

🧪 第 1 轮验证（逐条实测）

① 3.2 秒自动翻页 —— ✅ 通过，计时正常；
② 手动拖一下再松手 —— ❌ 不通过：轮播再也不自己翻了（Swiper 的 autoplay 默认 disableOnInteraction 为 true，用户一操作就停止，AI 没加这个参数）；
③ 点圆点 —— ❌ 不通过：圆点点了没反应（缺 clickable: true，默认只显示不可点）；
④ 拖到最后一张 —— ❌ 不通过：直接"顶死"回不去（缺 loop: true，没有无缝循环）；
⑤ cube 效果 —— ✅ 通过。
一句话结论：AI 第一次只实现了我字面上说的 3 条，漏了 3 条体验类需求——控制台不报任何错，只能靠动手验证发现。

🔁 第 2 轮提示词（针对漏项说清楚）

我（提示词 2）
刚才的配置实测有 3 个问题，请补全后给完整版：
① 我要无缝循环：翻到最后一张继续往后翻，要能回到第一张，请加 loop: true；
② 用户手动拖动、点圆点之后自动播放不能停止，要在 autoplay 里加 disableOnInteraction: false；
③ 圆点要能点击直接跳到对应那一张，pagination 里加 clickable: true。
其它（3.2 秒、cube）保持不变。
AI（回答 2）
理解，完整配置如下： 
new Swiper('#wySw4', {
  loop: true,
  autoplay: {
    delay: 3200,
    disableOnInteraction: false
  },
  pagination: {
    el: '#wyPag4',
    clickable: true
  },
  effect: 'cube',
  cubeEffect: { shadow: true, slideShadows: true }
});
loop 负责首尾无缝衔接；disableOnInteraction: false 表示用户交互后自动播放继续；clickable: true 让每个圆点可点击跳转到对应 slide。

🧪 第 2 轮验证

拖动松手后 3.2 秒内恢复自动翻页 ✅；点圆点直接跳转 ✅；最后一张继续往后翻无缝回到第一张 ✅；cube 正常 ✅。
一句话结论：4 条需求全部实测通过，配置已用在演示四里（初始效果就是 cube，点其它按钮可换效果）。

任务二 · creative 仿写课堂没讲的第 7 种 effect，让 AI 教我读懂官方 demo（257-effect-creative）

打开官方示例 swiper/demo/257-effect-creative.html 后，creativeEffect 里的 prev / next transform 写法看不懂，请 AI 讲解，并仿写"电影选片墙"效果，加到演示四的第 7 个按钮上。

💬 关键对话

我（提示词）
Swiper 有第 7 种 effect：creative。我看了官方 demo 257-effect-creative.html，里面 creativeEffect: { prev: { translate: [...], rotate: [...] }, next: {...} } 这种写法看不懂。我要做一个"电影选片墙"：上一张缩小左移并带一点角度，下一张放大右移，像站在电影海报墙前选片。请给我一版配置，并用大白话解释：prev 和 next 的 transform 各控制什么？translate 里的百分比相对谁？
AI（回答）
creativeEffect 是"自定义变换"效果：Swiper 会给每张 slide 算一个进度值（-1 ~ 1，表示它相对当前激活张的位置），然后把 prev / next 里定义的变换在这个进度上做插值。

prev 控制"正在退场的上一张"去哪儿——它离开中心后停在什么位置、什么角度；next 控制"即将进场的下一张"从哪儿来——进场前躲在哪个位置。

translate 的百分号相对该 slide 自身的尺寸（水平分量相对 slide 自己的宽度，垂直分量相对自己的高度），不是相对整个轮播容器；第三个数字是 Z 轴的像素值，负值是往屏幕里退（变小变远）、正值是往屏幕外迎（变大变近）。rotate 的第三个值是 2D 旋转角，单位是度；scale 是相对自身尺寸的缩放倍率。

电影选片墙配置参考： 
creativeEffect: {
  limitProgress: 2,
  shadowPerProgress: true,
  prev: {
    translate: ['-85%', 0, -320],  // 左移 85%（相对自身宽）、向内退 320px
    rotate: [0, 0, -12],           // 左倾 12 度
    scale: 0.7,                   // 缩小到 70%
    opacity: 0.55
  },
  next: {
    translate: ['85%', 0, 320],    // 从右侧 85% 进场、从外向内迎
    rotate: [0, 0, 12],            // 右倾 12 度
    scale: 1.05,                  // 放大到 1.05 倍
    opacity: 0.55
  }
}
注意 effect 要同时设为 'creative' 才会生效。
我（追问验证）
我照这版配置加到了页面的第 7 个按钮上，实测有效。再追问：如果我想让卡片转 20 度，改哪个数值？
AI（回答）
改 rotate 的第三个值即可：prev 的 rotate: [0, 0, -20]、next 的 rotate: [0, 0, 20]（一左一右对称）。改完刷新，两侧的海报倾角立刻变陡。

🧪 验证

点击第 7 个按钮「creative 电影墙」✅ 通过：上一张缩小左移左倾、下一张从右侧放大迎进，拖动时插值过渡自然，就是"选片墙"的感觉；把 rotate 改成 20 后两侧卡片倾角明显变大 ✅。
一句话结论：creative 效果 = 我自己定义"上一张的去向"和"下一张的来路"，Swiper 负责按进度插值。

任务三 · 综合创作 + 技术答辩第六件作品爱达·魔都号（AI 生图）+ thumbs 缩略图联动 + coverflow 大角度旋转

① 为光影展添加第六件作品爱达·魔都号（首艘国产大型邮轮，2024 年 1 月 1 日从上海吴淞口国际邮轮港开启商业首航），图片由 AI 生成（横版 16:9，文件 swiper-imgs/adora_1.jpg），各轮播的 slide 结构都补齐；② 主图与下方缩略图做 thumbs 双向联动，主图用 coverflow 封面流：centeredSlides: true 当前张居中、两侧露卡，coverflowEffect.rotate: 55 两侧卡片各转 55°、depth: 260 做出前后纵深，旋转堆叠最直观；附加能力 keyboard 键盘控制保留在演示台演示四。

💬 关键对话 1：新增第六件作品

我（提示词）
我的光影展页面用的是本地引入的 Swiper 11（script 引 swiper-bundle.min.js）。我要给 4 个轮播各加第 6 张 slide：作品名"爱达·魔都号"，设定是 2024 年 1 月首航的国产大型邮轮，图片是 AI 生成的 adora_1.jpg（16:9 横版）。给我一段和现有 slide 结构一致（swiper-slide + img + ztt-cap 标题说明）的 HTML。
AI（回答 1 —— 有瑕疵）
结构如下，图片路径按你页面的相对目录写： 
<div class="swiper-slide">
  <img src="swiper-imgs/adora_1.jpg" alt="爱达·魔都船">
  <div class="ztt-cap">
    <h3>爱达·魔都船</h3>
    <p>2024 年 1 月首航 · 国产大型邮轮扬帆起航</p>
  </div>
</div>
注意 4 个轮播的说明文字可以各写各的，但 img 路径和类名结构要保持一致，圆点分页器会自动多出一个点，不需要改 JS。
我（订正）
标题写错了：正式名称是爱达·魔都号，不是"魔都船"；配图初稿还是外链占位图，已换成本地 AI 生成的 adora_1.jpg。订正后四个轮播都用同一段结构。
🧪 验证：复制进 4 个轮播刷新后，每个轮播圆点变成 6 个，第 6 张图正常显示 ✅ 通过（图片由 AI 生成，16:9 横版，本地加载无外链依赖）。

💬 关键对话 2：keyboard 键盘控制（AI 第一次答错了）

我（提示词）
我要给演示四的 #wySw4 加键盘控制：按 ← → 键能翻页。要求页面滚动到其它区域时按键不要误触发轮播。给我 keyboard 配置并解释参数。
AI（回答 1 —— 有错）
用 Keyboard 模块： 
import Swiper from 'swiper';
import { Keyboard } from 'swiper/modules';

new Swiper('#wySw4', {
  modules: [Keyboard],
  keyboard: { enabled: true }
});
enabled: true 开启方向键翻页。
我（追问 + 指错）
报错了：我页面是 <script src="swiper-bundle.min.js"> 这种全量打包引入，没有用 npm / ES Module。第一版代码里 import 会直接报错吧？另外"滚动到别处不误触发"你还没解决。
AI（回答 2 —— 修正）
抱歉，我默认按 npm 工程的写法答了。你用的是 swiper-bundle 全量文件，所有模块已经内置，不需要 import、也不需要 modules 数组，直接写参数即可；"只在可视区域内响应"用 onlyInViewport: true： 
keyboard: {
  enabled: true,        // 开启 ← → 翻页
  onlyInViewport: true  // 轮播不在视口内时不响应按键
}
直接放进 new Swiper 的配置对象里就行。
🧪 验证：去掉 import / modules 后无报错；页面滚动到演示四可见时按 ← → 能翻页 ✅，滚到页面顶部时按方向键只滚动页面、轮播不动 ✅。
一句话结论：bundle 全量版 = 模块全内置，只写 keyboard 参数；AI 第一版错在按 npm 按需引入的语境作答，没先确认我的引入方式。

💬 关键对话 3：thumbs 缩略图联动（主图 ⇄ 缩略图双向同步）

我（提示词）
我想在页面上再做一个画廊：上面一张主图，下面一条缩略图。点任意一张缩略图，主图立刻跟着跳；主图翻页时，对应缩略图自动点亮。还是本地 swiper-bundle.min.js 全量引入。请给两个 Swiper 实例的配置，并说明两个实例的创建顺序。
AI（回答 1 —— 有瑕疵）
用 thumbs 模块：先 new 主图，再 new 缩略图，主图配置里写 thumbs: { swiper: '#zttThumbs' } 指向缩略图选择器；缩略图条配 spaceBetween、slidesPerView: 'auto'、watchSlidesProgress: true。激活的缩略图会自动加上 swiper-slide-thumb-active 类。
我（追问 + 指错）
实测联动没生效：主图翻了缩略图不点亮，点缩略图主图也不跳。两个问题——thumbs.swiper 到底该传选择器字符串还是实例对象？创建顺序是不是反了？
AI（回答 2 —— 修正）
两处都要改：
① 先 new 缩略图实例，再 new 主图实例——主图绑定 thumbs 时要拿到已经存在的缩略图实例，顺序反了绑定就是空的；
② thumbs.swiper 传的是实例对象，不是选择器字符串： 
var zttThumb = new Swiper('#zttThumbs', {
  spaceBetween: 8,
  slidesPerView: 'auto',
  freeMode: true,
  watchSlidesProgress: true,
  slideToClickedSlide: true
});
var zttMain = new Swiper('#zttMain', {
  effect: 'coverflow',
  centeredSlides: true,
  slidesPerView: 'auto',
  spaceBetween: 24,
  coverflowEffect: { rotate: 55, stretch: 0, depth: 260, modifier: 1, slideShadows: true },
  navigation: { nextEl: '#zttMainNext', prevEl: '#zttMainPrev' },
  thumbs: { swiper: zttThumb }
});
slideToClickedSlide: true 保证点哪张缩略图就把它带到可视区；点亮状态读 .swiper-slide-thumb-active 这个类所在的 slide 索引即可。
🧪 验证：点第 2 张缩略图，主图跳到第 2 张、缩略图同步点亮 ✅；点主图下一张，缩略图自动点亮到对应那张 ✅；读数显示"当前主图 / 点亮缩略图 / 已同步" ✅；主图两侧卡片以 55° 倾斜堆叠、纵深明显 ✅。
一句话结论：thumbs 联动 = 两个独立实例用 thumbs: { swiper: 实例 } 绑在一起，顺序先缩略图后主图，传对象不传字符串；主图套 coverflow，rotate: 55 + depth: 260 把旋转效果做明显。
