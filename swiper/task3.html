🖼 方案一：thumbs 双向联动

两个独立实例用 thumbs: { swiper: 实例对象 } 绑在一起。先 new 缩略图，再 new 主图；thumbs.swiper 传实例对象，不传选择器字符串。点哪张缩略图主图就跳到哪张，主图翻页时对应缩略图自动加 swiper-slide-thumb-active 类点亮。

🎞 方案二：coverflow 大角度旋转

主图用 effect: 'coverflow'，centeredSlides: true 让当前张居中、两侧露卡；coverflowEffect.rotate: 55 两侧卡片各转 55°，depth: 260 做出前后纵深，卡片明显斜着堆叠成封面流。

🎤 答辩要点（老师抽问就答这几条）

  • 这段代码什么意思？thumbs.swiper 把主图和缩略图实例绑定；slideToClickedSlide: true 点缩略图时把它带到可视区；watchSlidesProgress: true 让缩略图跟随主图进度点亮。
  • AI 第一次答的哪里不对？一是把创建顺序说成"先主图后缩略图"，实测绑定为空；二是 thumbs.swiper 让传选择器字符串，实际要传实例对象。两处订正后联动才生效。
  • 新参数的作用？rotate: 55 两侧卡片旋转角；depth: 260 纵深距离；centeredSlides: true 当前张居中；slidesPerView: 'auto' 按 slide 自身宽度排列，两侧卡片才能露出来。
  • 现场把 delay 改成指定值？本页主图未开自动播放；若加 autoplay.delay，改大则每张停留更久、改小则翻页更快；delay 只管停留时长，翻页动画快慢由 speed 控制。
// 先 new 缩略图实例
var ztt_thumb = new Swiper('#zttThumbs', {
  spaceBetween: 8,
  slidesPerView: 'auto',
  freeMode: true,
  watchSlidesProgress: true,
  slideToClickedSlide: true
});

// 再 new 主图实例，thumbs 传实例对象
var ztt_main = new Swiper('#zttMain', {
  effect: 'coverflow',
  centeredSlides: true,
  slidesPerView: 'auto',
  spaceBetween: 24,
  coverflowEffect: {
    rotate: 55,        // 两侧卡片大角度旋转（度）
    stretch: 0,
    depth: 260,        // 纵深
    modifier: 1,
    slideShadows: true
  },
  navigation: { nextEl: '#zttMainNext', prevEl: '#zttMainPrev' },
  thumbs: { swiper: ztt_thumb }
});
