第 7 种 effect：creative 电影选片墙

◀ prev · 退场的上一张去哪儿

prev 定义"离开中心的上一张"最终停在什么位置、什么角度。它在主图左侧缩小、左倾、退到屏幕里。

translate: ['-85%', 0, -320]水平左移自身宽度的 85%；垂直不动；Z 轴向屏幕里退 320px（变远）。
rotate: [0, 0, -12]绕 Z 轴逆时针转 12°（左倾 12 度）。
scale: 0.7缩小到自身尺寸的 70%。
opacity: 0.55半透明，弱化到背景层。

next · 进场的下一张从哪儿来 ▶

next 定义"即将进场的下一张"进场前躲在哪个位置。它在主图右侧放大、右倾、从屏幕外迎进来。

translate: ['85%', 0, 320]水平右移自身宽度的 85%；垂直不动；Z 轴向屏幕外迎 320px（变近）。
rotate: [0, 0, 12]绕 Z 轴顺时针转 12°（右倾 12 度）。
scale: 1.05放大到自身尺寸的 1.05 倍。
opacity: 0.55进场前半透明，靠近中心再变实。

🎤 答辩要点（老师抽问就答这几条）

  • translate 里的百分号相对谁？相对每个 slide 自身的尺寸——水平分量相对自己的宽度，垂直分量相对自己的高度，和整个轮播容器无关。
  • rotate 三个值各是什么？数组是 [X 轴, Y 轴, Z 轴]；第三个值是 2D 旋转角，单位是度，负值逆时针、正值顺时针。
  • 想让卡片转 20 度改哪个数？改 rotate 第三个值：prev 改 [0,0,-20]、next 改 [0,0,20]，一左一右对称，倾角立刻变陡。
  • creative 原理：Swiper 给每张 slide 算进度值（-1 ~ 1，相对当前激活张的位置），再把 prev / next 定义的变换在这个进度上做插值；我自己定义"上一张去向"和"下一张来路"，Swiper 负责过渡。
creativeEffect: {
  limitProgress: 2,        // 最多只给前后 2 张做变换，再远的隐藏
  shadowPerProgress: true, // 每张按进度投影，叠出海报墙层次
  prev: {
    translate: ['-85%', 0, -320],  // 左移 85%（相对自身宽）、向内退 320px
    rotate: [0, 0, -12],          // 左倾 12 度
    scale: 0.7,                   // 缩小到 70%
    opacity: 0.55
  },
  next: {
    translate: ['85%', 0, 320],   // 从右侧 85% 进场、从外向内迎
    rotate: [0, 0, 12],           // 右倾 12 度
    scale: 1.05,                  // 放大到 1.05 倍
    opacity: 0.55
  }
}
// 注意：effect 要同时设为 'creative' 这套变换才会生效
